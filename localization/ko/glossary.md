# 한국어 용어집

| 원문 | 한국어 | 사용 원칙 |
| --- | --- | --- |
| variable | 변수 | 값에 이름을 붙여 코드에서 사용하는 개념으로 설명합니다. |
| function | 함수 | 이름을 붙여 호출하는 코드 묶음입니다. 모든 함수가 값을 반환한다고 설명하지 않습니다. |
| parameter | 매개변수 | 함수 정의에서 입력을 받는 이름입니다. |
| argument | 인자 | 함수를 호출할 때 전달하는 값입니다. |
| member variable | 멤버 변수 | 함수 밖에 선언하여 같은 스크립트의 여러 함수에서 사용하는 변수입니다. |
| condition | 조건 | 코드가 어떤 분기를 선택할지 판단하는 식입니다. |
| boolean | 불리언(참/거짓) | 코드의 true, false 표기는 번역하지 않습니다. |
| loop | 반복문 | 코드를 여러 번 실행하는 문맥에서 사용합니다. |
| iteration | 반복 한 번 | 반복문이 한 차례 실행되는 단위입니다. |
| frame | 프레임 | 게임 화면을 한 번 갱신하는 단위입니다. |
| delta | 델타 시간 | 이전 프레임 처리에 걸린 시간을 초 단위로 나타낸 값입니다. |
| array | 배열 | 순서가 있는 값의 모음입니다. |
| index | 인덱스 | 배열 안에서 값의 위치를 나타내는 번호이며 첫 값은 0부터 시작합니다. |
| dictionary | 딕셔너리(키와 값의 모음) | 처음에는 풀어 쓰고 이후에는 딕셔너리로 통일합니다. |
| return | 반환 | 함수가 호출한 곳으로 값을 돌려주는 동작입니다. |
| type | 자료형 | 값이 어떤 종류인지 나타내는 정보입니다. |
| vector | 벡터 | 여러 축의 값을 하나로 묶어 위치·방향 등을 나타내는 값입니다. |

문체는 초보자에게 직접 설명하는 ~해요/~해 보세요체를 기본으로 합니다.
버튼은 실행, 힌트, 다시 풀기처럼 짧게 씁니다. 코드 식별자와 GDScript
키워드는 항상 원문 표기를 보존합니다.
